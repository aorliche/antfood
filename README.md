# Ant Food Diary

<img src='https://github.com/aorliche/antfood/blob/50c5f1ff6e1dc6156738ee6b0e78df3f0ccddf8e/src/icons/io.github.aorliche.antfood.svg' width='200'>

A text-first food, workout, and weight recorder and tracker. The database file is just a semi-structured text file that can be edited with any text editor.

The GUI takes that text file and organizes/summarizes it.

Edit the notes for each day like so:

<img src='https://github.com/aorliche/antfood/blob/50c5f1ff6e1dc6156738ee6b0e78df3f0ccddf8e/images/screenshots/edit_day.png' width='800'>

You can search for days that you performed a particular activity:

<img src='https://github.com/aorliche/antfood/blob/50c5f1ff6e1dc6156738ee6b0e78df3f0ccddf8e/images/screenshots/search.png' width='800'>

Interactive graph gives you the details of your diet over time:
